# Данные

Исходные CSV в репозиторий не входят (≈135 МБ). Набор — Brazilian E-Commerce Public Dataset by Olist и Marketing Funnel by Olist в выгрузке «Ecommerce csv dumps» (CSV с табуляцией, `NULL` для пустых значений).

Распакуйте архив так, чтобы файлы лежали прямо в `data/raw/`:

```
data/raw/Orders.csv
data/raw/Order_items.csv
data/raw/Order_payments.csv
data/raw/Order_reviews.csv
data/raw/Products.csv
data/raw/Product_category_name_translation.csv
data/raw/Sellers.csv
data/raw/customers.csv
data/raw/geolocation.csv
data/raw/leads_qualified.csv
data/raw/leads_closed.csv
```

Оригинал на Kaggle: <https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce> и <https://www.kaggle.com/datasets/olistbr/marketing-funnel-olist>. Отличия этой версии от оригинала перечислены в разделе «Ограничения» основного README.
