# Дашборд в Yandex DataLens

Дашборд собирается из CSV в папке `marts/` — локальная база DataLens недоступна, поэтому используется подключение «Файлы». Около 30–40 минут.

## 1. Подключение и датасеты

1. <https://datalens.yandex.ru> → войти аккаунтом Яндекса → **Создать → Подключение → Файлы**.
2. Загрузить все файлы из `marts/`. Проверить типы полей: `purchase_month` и `cohort_month` — **Дата**, проценты и суммы — **Дробное число**. Сохранить подключение как `olist_marts`.
3. Для каждого файла: **Создать датасет** на подключении `olist_marts`. Имена датасетов — как у файлов.

## 2. Чарты

| № | Датасет | Тип | Настройка |
|---|---|---|---|
| 1 | monthly_kpi | Индикатор ×3 | `sum(orders)`, `sum(gmv)`, `avg(late_pct)` — заголовки «Заказы», «Выручка, BRL», «Опоздания, %» |
| 2 | monthly_kpi | Линейная | X: `purchase_month`, Y: `orders`. Фильтр: `purchase_month` с 2017-01 по 2018-08 |
| 3 | monthly_kpi | Линейная | X: `purchase_month`, Y: `late_pct`. Отдельный чарт, не вторая ось |
| 4 | delay_vs_review | Столбчатая | X: `delay_bucket`, Y: `negative_review_pct`, сортировка по `delay_bucket` |
| 5 | cohort_retention | Таблица → «Сводная таблица» | Строки: `cohort_month`, столбцы: `month_offset`, показатель: `retention_pct`; раскраска — градиент одного цвета. Фильтр: `month_offset` от 1 до 12 |
| 6 | delivery_by_state | Столбчатая горизонтальная | Y: `customer_state`, X: `late_pct`, сортировка по убыванию; фильтр `delivered_orders > 500` |
| 7 | seller_funnel | Столбчатая горизонтальная | Y: `origin`, X: `conversion_pct`; в подсказку добавить `mql` |
| 8 | category_kpi | Таблица | `main_category`, `gmv`, `gmv_share_pct`, `avg_review`, `late_pct`; сортировка по `gmv` |
| 9 | rfm_segments | Столбчатая | X: `segment`, Y: `customers`; в подсказку `gmv` |

## 3. Дашборд

**Создать → Дашборд** `Olist: продуктовая аналитика`. Порядок сверху вниз:

1. Индикаторы (чарт 1) в один ряд.
2. Заказы (2) и опоздания (3) рядом.
3. Опоздание и отзывы (4), опоздания по штатам (6).
4. Когорты (5) на всю ширину.
5. Воронка продавцов (7), RFM (9), категории (8).

## 4. Публикация

1. **Поделиться → Публичный доступ**, включить для дашборда и всех его чартов и датасетов.
2. Скопировать ссылку и вставить в README репозитория в строку про дашборд.
